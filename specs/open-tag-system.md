# `speak` — Claude Tag & Open Tag (@mention) Architecture

> **Official Inspiration**: Anthropic's **Claude Tag** (`https://claude.com/docs/claude-tag/overview`), Claude Code Agent Teams, Mattermost AI Copilot, and Zulip.

---

## 1. Claude Tag Breakdown: The Industry Standard

**Claude Tag** is Anthropic's official Slack integration:
1. **Tag `@Claude` into a problem**: Anyone in a channel can type or speak `@Claude` to hand off complex engineering or operational work:
   - *"@Claude reproduce this bug and open a pull request"*
   - *"@Claude compare latency against this morning's deploy and find what's causing it"*
   - *"@Claude turn this decision thread into a doc"*
2. **Live Thread Checklists**: When `@Claude` accepts a task, it immediately posts a live updating task list inside the thread:
   - `[Done]` Pulled p99 latency from Datadog
   - `[Done]` Diffed deploy `4f2c1` against main
   - `[Done]` Reproduced the slow query locally
   - `[In Progress]` Opening a pull request with the fix...
3. **Channel-Wide Visibility**: All team members see the progress, evidence, and final results in the thread without context pollution.

## 3. Spoken Open Tag Syntax & Grammar

`speak`'s `VoiceCommandParser` recognizes tag patterns in spoken voice or typed turns:

### Tag Patterns
- **Individual Agents**: `@Claude`, `@codex`, `@builder-audio`, `@builder-qa`
- **Agent Teams**: `@engine-team`, `@qa-team`, `@frontend-team`
- **Scope Tags**: `@channel` (broadcast to channel), `@here` (active working agents)

### Example Voice Inputs
- *"Tag Claude compare latency before and after the deploy"*
- *"Tag audio-team refactor the speech synthesizer continuation"*
- *"Tag qa-team run full moat verification"*

## 4. Technical Architecture: Thread Checklists & Evidence Cards

### A. Dynamic Task Checklist Schema (`AgentEvent.TaskChecklist`)
Agents stream progress updates that render as interactive checklists in the `speak` thread view:

```json
{
  "callId": "call-8812",
  "sessionId": "claude-code-session-1",
  "channel": "#core-engine",
  "tag": "@Claude",
  "checklist": [
    { "id": "task-1", "title": "Inspect AudioCapture.swift line 87", "status": "done" },
    { "id": "task-2", "title": "Insert removeTap guard before installTap", "status": "done" },
    { "id": "task-3", "title": "Run Xcode build & verify zero errors", "status": "in_progress" }
  ]
}
```

### B. Rich Evidence Attachments
- 📸 **Screenshots**: Rendered UI or test output images.
- 📹 **Recordings**: Screen recordings of test executions.
- 📄 **Code Diffs**: Interactive patch diffs.
- 🎙️ **Audio Summaries**: Voice readback snippets generated by `AppleSpeechSynthesizer`.

---

## 5. Security & Privacy Guarantees

1. **100% On-Device Local First**: Conversations, thread histories, and evidence cards are stored locally in SQLite (`~/Library/Application Support/speak/workspace.sqlite`).
2. **Zero Unsanctioned Egress**: Local MCP stdio & CLI transports keep your code and voice private.
3. **Write-Only Pasteboard & Permission Gating**: No agent gets ambient microphone or screen access without explicit user action.
